# 🚉 RailPulse AI: Intelligent Transit Insights 

- **Repository:** `railpulse-genai-challenge`
- **Type of Challenge:** `Learning`
- **Duration:** `5 days`
- **Deadline:** `dd/mm/yy 5:00 PM`

## The Mission

> We are *RailPulse*, an urban mobility consulting firm. The Belgian National Railway company (SNCB/NMBS) has successfully modernized its infrastructure: data flows seamlessly from the iRail API through your serverless cloud pipeline into Azure SQL, and executives are tracking live trends on your Power BI Dashboard. 
> 
> For the final milestone, the executive board wants to leverage **Open-Source Generative AI** to make this data conversational and actionable. Your mission is to build an intelligent, completely free-to-run AI assistant that connects to your existing data infrastructure. It must translate complex transit data into natural language recommendations for station managers without incurring third-party API costs.

---

## Mission Objectives

Consolidate your knowledge in Generative AI engineering, specifically using open-source tools:
- **Local & Free LLM Integration:** Hooking up open-source models (like Llama 3 or Mistral) locally via Ollama or through free-tier open-source inference APIs (like Groq).
- **Text-to-SQL / Contextual Routing:** Structuring prompts that allow smaller open-source models to accurately translate natural language into SQL queries without hallucinating.
- **Agentic Guardrails:** Designing strict programmatic and prompt-based filters to block unauthorized or destructive database operations (e.g., preventing SQL injections).

---

## Must-Have Features: The Operational AI Co-Pilot

### Objective
Create a localized, free GenAI application using Python and open-source models that securely connects to your database to act as an on-call **Railway Operations Assistant**.

### Core Functionality
1. **Deterministic Text-to-SQL Translation:** Users must be able to type natural language questions (e.g., *"Which platform at Brussels-Central had the worst average delay this morning?"*). The open-source LLM must generate the correct SQL query, execute it against your schema, and present the findings.
2. **Context-Aware Consulting:** The model must be explicitly prompted to act as a *RailPulse Consultant*. It shouldn't just state raw database outputs; it must provide a brief tactical recommendation (e.g., alerting operations to platform bottlenecks).
3. **Metric Conversion:** Raw delay metrics are stored in seconds. Your application layer or prompt must systematically convert these into minutes for human-readable summaries.
4. **User Interface:** A simple interactive chat portal built using Streamlit or Chainlit allowing non-technical stakeholders to talk directly with the network data.


## Nice-to-Have Features: Automated Executive Briefings

Ready to push your open-source AI agent to production-grade status? 

1. **Strict Query Validation (Safety Layer):** Implement a Python-level regex or execution guardrail that intercepts the LLM's generated query and instantly blocks it if forbidden keywords like `DROP`, `DELETE`, or `UPDATE` are detected.
2. **Dynamic Few-Shot Prompting:** To help smaller 8B open-source models understand your exact schema, implement a few-shot examples block in your prompt template matching sample user questions to perfect SQL queries.
3. **Automated Weekly Report Generator:** Create a local script that extracts the top 5 delay anomalies from your database and uses the open-source LLM to write a professional Markdown executive brief.


## Constraints

- LLM Choice: You must use open-source infrastructure. Run models locally via Ollama or connect to Groq using their free developer tier API keys.

- Database Hook: Use Python's built-in sqlite3 or pyodbc connectors to execute the queries generated by the model safely.

## Deliverables
* ✅ A GitHub repository containing your application source code.
* ✅ A fully documented local setup guide (e.g., instructions on running `ollama run llama3`).
* ✅ A robust prompt engineering file (`prompts.py`) showcasing advanced structural guidelines tailored for open-source models.
